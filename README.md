# AniWatch

Your anime series and movies, on your own PC, like a streaming service. Windows 10/11, 64-bit.

**[Download](../../releases/latest)** · Setup.exe or portable zip

## Features

- Reads your existing folders; nothing moved or renamed
- Series and anime movies
- Plays every file as it is (MKV, HEVC, 10-bit, dual audio, styled subtitles)
- Subbed or dubbed, your choice
- Picks up where you left off; plays the next episode
- Details from AniList and MyAnimeList
- Pop-out player
- Watchlist and history
- Updates itself
